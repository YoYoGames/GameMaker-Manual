draw_set_valign

This function is used to align text along the vertical axis and changing the vertical alignment will change the position and direction in which all further text is drawn, with the default value being fa_top.

The following constants are accepted:

 If you use this function to set the vertical text alignment, remember to reset it back to the default value using draw_set_valign(fa_top); at the end of the event. Otherwise, the modified alignment will continue to apply to other text drawn after that and cause unexpected offsets. See also: GM2019

 

Syntax:

draw_set_valign(valign)

Argument Type Description
valign Vertical Alignment Constant Vertical alignment constant (from the table above).

 

Returns:

N/A

 

Example:

draw_set_halign(fa_center);
draw_set_valign(fa_middle);
draw_text(100, 32, "Score: " + string(score));
draw_set_halign(fa_left);
draw_set_halign(fa_top);

The above code will draw the score centered around the very center of the text.
