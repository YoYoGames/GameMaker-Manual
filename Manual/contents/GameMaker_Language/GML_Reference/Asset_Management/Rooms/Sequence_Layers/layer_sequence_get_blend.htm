layer_sequence_get_blend

This function returns the current blend colour for the given sequence element. You supply the sequence element ID - as returned by layer_sequence_create or by one of the layer element functions.

 

Syntax:

layer_sequence_get_blend(sequence_element_id)

Argument Type Description
sequence_element_id Sequence Element ID The unique ID value of the sequence element to target

 

Returns:

Colour

 

Example:

image_blend = layer_sequence_get_blend(title_sequence);

The above code gets the colour of the sequence element ID stored in the variable title_sequence and applies that to the instance's image_blend.
