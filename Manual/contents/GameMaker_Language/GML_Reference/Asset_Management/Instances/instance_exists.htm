instance_exists

This function can be used in two ways depending on what you wish to check. You can give it an object index to check for, in which case this function will return true if any active instances of the specified object exist in the current room, or you can also supply it with an instance id, in which case this function will return true if that specific instance exists and is active in the current room.

 This function does not take into account those instances that have been deactivated using the instance deactivate functions.

 When the function is called within a Create event, it only checks for instances that already exist in the room at that point in time. Instances placed in the Room Editor are created one at a time in the order they appear in the Instance list, so the result of this function depends on which instance was created first. For example, if a room contains an instance of obj1 and an instance of obj2, and obj2 is created first, then when obj1's Create event runs, instance_exists(obj2) will correctly return true. However, if obj1 is created first, then there is no instance of obj2 in existence when its Create event runs, so instance_exists(obj2) will return false. You can change the creation order of instances in the Room Editor.

 

Syntax:

instance_exists(obj)

Argument Type Description
obj Object Instance or Object Asset The object or instance to check for the existence of

 

Returns:

Boolean

 

Example:

if (!instance_exists(obj_enemy))
{
    score += 200;
    room_goto(rm_hiscores);
}

The above code checks to see if any instances of an object obj_enemy exist and if not it adds to the variable score and changes room.
