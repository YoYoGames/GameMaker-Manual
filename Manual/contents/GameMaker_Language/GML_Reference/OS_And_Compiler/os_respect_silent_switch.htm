os_respect_silent_switch

This function sets whether the silent switch on iOS is respected or not.

By default, this is set to false meaning the game plays audio regardless of the state of the silent switch. Setting this to true disables game audio when the phone is set to silent.

See Apple's guidelines on when the silent switch should be respected. As per the categories documented on the linked page, the game will make use of one of the following categories depending on its state:

  • Ambient: This category is used when the silent switch is being respected.
  • Playback: This category is used when the silent switch is being overidden (default behaviour). Exception: The game will never play audio in the background.
  • Play and record: This category is used when audio is being recorded. Exception: The game will never record or play audio in the background.

 The silent switch cannot be respected while audio is being recorded. During recording, the game will temporarily switch to overriding the silent switch.

 

Syntax:

os_respect_silent_switch(enable)

Argument Type Description
enable Boolean Set to true or false to respect or override the silent switch.

 

Returns:

N/A

 

Example:

os_respect_silent_switch(true);

This enables the silent switch, ensuring the game is muted when the phone is set to silent.
