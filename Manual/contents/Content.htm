Welcome to the GameMaker manual!

GameMaker 101

If you're new to GameMaker, head over to Hello World: GameMaker! to get your first game up and running.

Follow the pages of the Quick Start Guide to get your intro to the various parts of GameMaker.

Contents

This manual is divided into the following sections:

Intro & Set Up

  • Introduction To GameMaker: Describes the fundamental basics of the GameMaker IDE
  • Quick Start Guide: Introduction to programming a game in GameMaker
  • Installation & Setting Up: Information on installing, logging in and various set-up related questions

Editor Settings

  • GameMaker IDE: The general editors, preferences and tools available in GameMaker
  • GameMaker Runner Settings: Settings that affect your game at runtime
  • The Asset Editors: Editing information on all of GameMaker's asset types

Programming in GameMaker

  • GameMaker Guides: Guide pages that don't fall under particular categories
  • GameMaker Language: Complete reference documentation for GML Visual and GML Code

 Due to the modular nature of GameMaker there are certain things that are not included in this user manual, in particular those aspects of setting up and connecting the different devices that can be supported. For up-to-date information and troubleshooting hints and tips related to the different target platforms, please see the GameMaker Wiki and GameMaker Help Center (for legacy information and help articles).
